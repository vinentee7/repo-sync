# Registro de atividades

Este repositório registra minhas contribuições realizadas no GitLab corporativo, permitindo que essas atividades também apareçam no meu histórico do GitHub.

A sincronização é feita pelo **GitSync**, que consulta meus eventos no GitLab e cria commits vazios com as datas das atividades originais.

São registradas atividades como:

- Commits enviados.
- Merge requests integrados.
- Aprovações de merge requests.

Cada registro possui uma referência ao evento de origem para evitar duplicações nas próximas sincronizações.

## Privacidade

Este repositório armazena apenas registros de atividade. Nenhum código-fonte, arquivo ou conteúdo dos projetos corporativos é copiado para cá.

## Sobre os commits

Os commits são gerados automaticamente e preservam as datas das contribuições originais. Por isso, o histórico pode conter registros anteriores à criação deste repositório.
